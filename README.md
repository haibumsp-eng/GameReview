# GameReview

Mổ băng trận đấu bóng rổ cho HLV: đánh dấu tình huống theo mốc thời gian, gắn cầu thủ / tấn công / phòng thủ, bình luận, lọc và phát lại các đoạn đã lọc.

    npm install
    npm run dev

- Video: dán link YouTube (unlisted). Không cắt file thật: mỗi mark lưu start/end, playlist tự tua qua các đoạn.
- Phím tắt: Space phát/dừng, J/L ±5s, A tấn công, D phòng thủ, Del xoá mark.
- Dữ liệu hiện lưu trong localStorage (chế độ demo). Bản nhiều HLV dùng supabase/schema.sql, chưa nối.
